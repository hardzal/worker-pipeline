# Enforce source grounding through prompts without output evidence

Study Guides must remain grounded in Source Material, but the public result schema will not include exact source quotations or evidence references. Grounding is enforced through prompt design and evaluated as a model-quality requirement rather than validated as a deterministic application invariant. This keeps the result compact, with the accepted trade-off that schema validation alone cannot prove factual grounding and adding evidence fields later would change the output contract.
